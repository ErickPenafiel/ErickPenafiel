## Qué construyo

- **Agentes de voz** que toman pedidos, agendan reservas y pasan a una persona cuando hace falta (Vapi/Retell + FastAPI, con panel en vivo).
- **Agentes de chat y soporte** con LLMs y RAG (LangGraph, Qdrant, Ollama) que responden solo con la base de conocimiento del negocio. Un asistente que construí resolvía ~80 % de las consultas de clientes sin intervención humana.
- **Automatización con WhatsApp**: mensajería multi-sesión, comprobantes y notificaciones.
- **Backends y APIs** en FastAPI, NestJS y Laravel, con colas (RabbitMQ), Docker y CI/CD con GitHub Actions.
